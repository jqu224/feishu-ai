# 提问路径（Mock）· 去哪里问、什么问题、该怎么问

> 虚构演示数据（示例科技）。真实使用时由用户自己的 onboarding 文档替换。

## 一、提问渠道地图

新人遇到问题，先按这张表选渠道，不要盲发。

| 问题类型 | 例子 | 去哪里问 | 期望响应 |
|---|---|---|---|
| 工具使用 | 飞书怎么建日程、文档怎么设权限、豆包工作怎么装技能 | 先问 **AI 伙伴**（小笼）→ 查文档中心 → 再问同事 | 即时 |
| 账号 / 权限 / 网络 | 邮箱登不上、Wi-Fi 连不上、系统没权限 | **IT 工单系统**（工单：it.example.com） | 1 个工作日 |
| 业务 / 流程 | 报销怎么走、审批流程、项目立项 | **直属 leader** 或业务文档（知识库） | 当日 |
| 技术问题 | 代码报错、接口不通、组件怎么用 | **技术群** @对应模块 owner → 代码库/文档 | 1–4 小时 |
| 制度 / 福利 | 年假、社保、差旅标准 | **HR 伙伴**或制度文档（福利站） | 1 个工作日 |
| 产品 / 需求 | 需求文档有冲突、优先级不明 | **产品负责人**，带上证据和影响面 | 当日 |

## 二、怎么问（BGTA 提问模板）

完整提问 = 四段式 BGTA：

- **B**ackground 背景：我在做什么、上下文是什么
- **G**oal 目标：我想达成什么
- **T**ried 已尝试：我已经试过什么、结果如何
- **A**sk 请求：具体需要对方做什么

**反例（不要这样问）**：「在吗？」「这个怎么弄？」「帮我看看」（无上下文截图）。
**正例**：「我在写新人 onboarding 文档（B），想给新人配飞书文档权限（G），试过分享-添加协作者但找不到搜索框（T），能告诉我在哪设置吗（A）？」

## 三、提问的优先级原则

1. **先搜后问**：文档、知识库、群精华里有的，先自己找；找不到再问
2. **一次问全**：把相关背景一次给足，避免来回追问
3. **带上证据**：截图、报错信息、链接，能贴就贴
4. **就事论事**：不评判人、不带情绪；被指出问题时先确认事实
5. **问完归档**：有价值的问答沉淀到团队文档，下个新人不用再问

## 四、新人 FAQ（高频问题速查）

1. **Q：入职第一天要做完什么？** A：领电脑、装飞书并加入部门群、完成账号开通与安全培训、和 leader 对齐本周任务。（详见《入职日程与组织》）
2. **Q：Wi-Fi / VPN 连不上怎么办？** A：走 IT 工单（it.example.com），附设备型号和错误截图。
3. **Q：怎么加公司文档库？** A：在飞书「知识库」搜索团队空间申请加入，或找 leader 拉你。
4. **Q：代码仓库在哪？** A：公司代码平台 code.example.com，用企业邮箱登录，入职后自动开通权限。
5. **Q：设计稿在哪看？** A：Figma（figma.example.com），组件规范见《组件与网址》。
6. **Q：报销怎么走？** A：财务系统 expense.example.com 提交，附发票和审批链；标准见制度文档。
7. **Q：每天要写日报吗？** A：团队用周报 + 周会同步，具体按团队惯例，问 leader 确认。
8. **Q：遇到技术问题不知道该问谁？** A：先看代码库 README 的 owner 列表，再在技术群 @ 对应模块 owner。
9. **Q：30-60-90 天计划怎么定？** A：模板见《入职日程与组织》，和 leader 对齐后写入团队文档。
10. **Q：压力大、焦虑怎么办？** A：可以随时说「解压」让小笼带你做呼吸或 54321 练习；严重情绪问题建议联系公司心理咨询服务（HR 伙伴可预约）。
