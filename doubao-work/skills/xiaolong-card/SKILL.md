# 小笼卡片技能

帮用户在飞书群里发起交互卡片（投票 / 报名 / 表单），成员在群里点击即投、原地统计，全程无需离开飞书。

## 前置条件

小笼 AI 连接器（`xiaolong-doubao-work`）已配置并选中。调用工具前不需要用户提「小笼」——只要意图是投票/报名/收集，就用下面的工具。

## 工具选择

| 用户意图 | 工具 | 说明 |
|---|---|---|
| 投票（选择题，2-8 个选项） | `create_vote` | 如「下午茶喝什么：奶茶/咖啡/果茶」 |
| 给一份名单统计报名 | `create_roster_form` | 名单 ≤100 人，自动生成「姓名下拉 + 能否参加」 |
| 其它收集（多个自定义字段） | `create_form` | ≤6 个字段，text/select 混合 |
| 查进度 | `get_session_status` | 需要创建时返回的 session_id |
| 导出结果 | `export_session_summary` | 文本汇总，含每人明细 |

创建类工具都会把卡片发进飞书会话并返回 `session_id`——**务必把 session_id 记录在回复里**，用户后续问「报名情况如何」时要靠它查询。

## 参数要点

- `chat_id` 不填 = 发到默认会话；用户明确指定其他群时才传。
- `create_roster_form` 的名单直接用用户提供的数组，**不要自己缩水**；超过 100 人时报错，如实告知并建议拆两批。
- `create_form` 的 select 字段 `options` ≤100 个；text 字段不要传 options。
- 选项/字段保持用户原文的措辞与顺序，不要润色。

## 示例话术

**投票**：「帮我发起个投票，问题：周五团建去哪，选项：骑行 / 露营 / 采摘」→ 调 `create_vote`。

**100 人报名**（本技能的招牌场景）：用户给出一份 100 人名单并要求统计报名 → 调 `create_roster_form`，`names` 传完整数组：

```json
{
  "title": "全员大会报名",
  "names": ["张三", "李四", "王五", "...（共 100 个）"]
}
```

**混合表单**：「收集团建信息：姓名（必填）、忌口（选填）、交通方式（下拉：大巴/自驾/地铁）」→ 调 `create_form`。

## 查询与导出

用户问「报名情况」「统计到哪了」时，先从对话上文找回 session_id，再调 `get_session_status`；用户要结果明细时调 `export_session_summary`，把返回的 text 原样展示或继续加工成表格/文档。

更多示例与故障排查见 [references/examples.md](references/examples.md)。
