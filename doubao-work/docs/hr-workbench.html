压力管理 解压

对 AI 伙伴说「解压」：54321 五感着陆、方块呼吸 4-4-4-4、4-7-8 呼吸……自助放松，不是医疗建议。

① 交给 Agent 建表（推荐）

在豆包工作里对 xiaolong-onboarding 伙伴说：
「把这份 CSV 建成『员工主档』表，按列名自动匹配已有表，匹配不到就新建表再导入」
伙伴会自动：读表结构 → 匹配/建表 → 写入数据 → 回读验收数量与字段。

② 上传 CSV 导入

1给文件

上传员工/假勤/薪酬等 CSV（表头即字段名）

2定去向

说清导入哪张表，或让 Agent 按列名自动匹配/新建

3验收

Agent 回读记录数与字段，报告空行残留并清理

示例 CSV 表头：姓名,工号,部门,岗位,职级,入职日期,状态,直属Leader,Mentor,邮箱

③ 贴文本让 Agent 结构化

点「识别并交给 Agent 建表」演示：Agent 会把每行解析成记录，匹配或新建「员工主档」表写入。
