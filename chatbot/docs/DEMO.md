# 3 分钟 Demo 脚本

发布到小红书 / 抖音 / B 站 / 视频号之一，标题带话题 `#飞书 AI 绝活大会`。建议竖屏 9:16、字幕 + 节奏快剪。

## 分镜（约 150 秒）

1. **开场（10s）**：一句话点题——「团队群里那些投票、报名、接龙，别再打字接龙了，一句话就能变成可交互卡片」。
2. **痛点（20s）**：演示旧流程——复制问卷链接、跳出去、回来发截图、人工数票。
3. **猜拳闭环（40s）**：`@机器人 猜拳` → 连点三次，展示卡片**原地更新**胜负和累计战绩 → 重置。
4. **AI 投票（35s，主菜）**：`@机器人 发起一个下午茶投票：奶茶 / 咖啡 / 果茶` → AI 生成投票卡 → 多人点击 → 票数实时增长 → 点「结束并公布」→ 出现**人工确认**卡 → 确认后才公布结果。
5. **对话式改卡（20s，最抓人镜头）**：投票发出后随口补一句「哦对，再加个选项：果茶换成柠檬茶」→ 原卡片**原地变了**，配字幕「别家 AI 是一次性生成，我们的卡片是活的」。
6. **AI 报名表（15s，附带）**：`@机器人 收集团建报名：姓名、能否参加、忌口` → AI 生成表单卡（输入框 + 选择器）→ 成员原地提交 → 汇总 → 人工确认后公布。
7. **AI 信息卡 + 导出文档（15s）**：一句话生成 Markdown 信息卡（留意底部 `模型名 · 耗时` 小字）→ 点「导出为文档」→ 群里收到飞书在线文档链接，配字幕「结果直接沉淀成文档」。
8. **结尾（10s）**：前后对比 + 一句反馈金句。

## 三句对标讲解词（评委问答 / 视频旁白钉死）

1. **对标官方最强场景**：「飞书官方 aily 的第一场景是话题群知识库答疑——我们同样做知识问答，但答案是一张能继续操作的卡片，不是一段文本。」
2. **对标行业安全标准**：「企业微信智能机器人的敏感操作一律二次确认——我们的确认闸门是同一个标准：公布、导出都必须人点一下『确认执行』才生效。」
3. **对标结果沉淀**：「WorkBuddy 的主打是『对话进、文档出』——我们的投票/报名汇总一键导出飞书在线文档，组织内可读，可以直接进评审材料。」

## 前后对比数据（请用真实数据替换）

对标官方 OTO 案例的讲法（提单 10 分钟 → 2 分钟、错误率 10% → 0%），量化数字是评委记忆的锚点：

| 场景 | 传统方式 | AGUI 卡片 |
| --- | --- | --- |
| 发起投票到收齐 8 人结果 | 约 6 步 / 3 分钟，人工数票 | 1 句话 10 秒发起 + 每人点 1 下，自动统计 |
| 改一个投票选项 | 撤回重发、重新接龙、已投的票作废 | 说一句话，原卡原地改，已投票数保留 |
| 发起方操作 | 复制链接、发群、回收截图、统计 | 一句话 @机器人 |
| 参与方操作 | 跳转外链、填表、截图 | 点一个按钮 / 原地填卡片 |
| 结果归档 | 手动整理成文档 | 一键导出飞书在线文档 |

## 真实反馈收集

跑通后找 3-5 个真实同事/朋友试用，收集 2-3 条原话，例如：

- 「不用跳出去填问卷，群里点一下就完事。」
- 「以前接龙乱糟糟，现在谁投了没投一眼看到。」

把这些真实数字和原话写进「项目介绍」，比功能列表更有说服力。
