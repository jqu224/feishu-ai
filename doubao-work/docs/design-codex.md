# Onboarding 每日成长工作台 · 设计法典（Design Codex）

> 版本：v1.0 · 2026-09-11
> 载体：`doubao-work/docs/marketplace.html`（自包含单文件，零外部依赖）
> 定位：每个员工打开一个网址 = 自己的每日成长工作台；浅色默认白底，右上角太阳/月亮一键切深色。

---

## 1. 设计原则

1. **多巴胺 neo-brutalism**：粗黑描边 + 硬投影 + 高饱和撞色，让人「有活力地上班」。
2. **白底为主，深色可选**：浅色是默认主题（白底）；深色主题是「黑金多巴胺」——黑底 + 亮黄 primary，不是纯黑也不是暖土黄。
3. **黄为深色主色**：深色模式下，描边、主按钮、导航高亮、旅程进度全部用亮黄 `#ffd21f`，整体只有一个主角色；霓虹多色只作小面积图标点缀。
4. **两栏式卡片语言**：图标在左、文字在右，拒绝竖排堆叠与「报流水账」。
5. **全局禁 emoji**：一律 Google Material Icons（内联 SVG path，零网络依赖）；字符画（Hangman 绞架、`\o/` 庆祝）不算 emoji，保留。
6. **克制使用深色大块**：仅 Header、遮罩、旅程卡可深色；Main body 不整块压深。

## 2. 双主题 Token（CSS 变量 SSOT）

### 2.1 浅色（默认，白底多巴胺）

```css
:root{
  --bg:#ffffff; --card:#ffffff; --soft:#f6f7f4;
  --edge:#161616; --edge-soft:#dcdcd4;
  --text:#141414; --sub:#6f6f6a; --sub-2:#9b9b94;
  --btn-bg:#161616; --btn-fg:#ffffff;            /* 主按钮黑底白字 */
  --blue:#0e7490; --blue-bg:#cffafe;             /* 强调青蓝（旅程卡硬影用） */
  --map-bg:#fef3c2; --map-sc:#0e7490;            /* 柠檬黄旅程卡 + 青蓝硬影 */
  --header-bg:#161616; --header-edge:#ffd21f;    /* 黑 Header + 亮黄底边 */
  --shadow:4px 4px 0 var(--edge);
}
```

### 2.2 深色（黑金多巴胺）

```css
[data-theme="dark"]{
  --bg:linear-gradient(170deg,#141412 0%,#0f0f0e 48%,#0a0a09 100%); /* 冷黑分层，非纯黑 */
  --card:#171716; --soft:#20201e;
  --edge:#ffd21f; --edge-soft:rgba(255,210,31,.3);   /* 全卡片亮黄描边 */
  --text:#f6f5ef; --sub:#a8a69b; --sub-2:#6f6d63;
  --btn-bg:#ffd21f; --btn-fg:#16130a;                /* 主按钮亮黄底黑字 */
  --blue:#ffd21f; --blue-bg:rgba(255,210,31,.16);    /* 蓝色语义全部映射为黄 */
  --map-bg:#1a160a; --map-sc:rgba(0,0,0,.85);        /* 深琥珀卡 + 黑硬影 + 黄描边 */
  --header-bg:#0c0c0b; --header-edge:#ffd21f;
  --shadow:5px 5px 0 rgba(0,0,0,.75);
}
```

> **设计要点**：深色下 `--blue` 被映射为黄，因此 `.eyebrow`、`track-detail` 百分比、选中态描边、输入 focus、modal kicker 等所有原「蓝色强调」自动变黄，上下半页统一，不再出现「上黄下蓝」的割裂。

## 4. HCT 思路（为什么这样配）

- **Tone（色调）**：深色主色取纯黄相 `60°`（`#ffd21f`），与黑色背景对比度约 10.6 : 1，可读且醒目；避免把主色做成蓝相，因为蓝与黄相撞会形成「上黄下蓝」的双主角割裂。
- **Chroma（色度）**：primary 用高彩度黄（亮黄）；辅色霓虹化但收窄面积（仅图标 38 px 方块、进度条），大面积背景保持低彩度冷黑，保证「多巴胺但不脏」。
- **Tone（明度）**：背景分层 `#141412 → #0a0a09`（每层差 2–4 档）产生纵深，而不是一个纯黑平涂；卡片 `#171716`、辅助面 `#20201e` 逐级抬升。
- **对比度基线**：正文 `#f6f5ef` on `#171716` ≈ 15 : 1；次要 `#a8a69b` ≈ 7.5 : 1；黄 primary 上的黑字 `#16130a` ≈ 10 : 1。

## 5. 描边 · 阴影 · 圆角 · 字体 · 间距

| Token | 规范 |
|---|---|
| 描边 | 卡片 2 px（`--edge`）；旅程卡 2.5 px；按钮 2 px |
| 阴影 | 默认 `4px 4px 0` 硬影；hover `6px 6px 0`；旅程卡 `6px 6px 0` |
| 圆角 | 卡片 `12 px`；图标块 `10 px`；按钮 `9 px`；胶囊 `99 px` |
| 字体 | 知乎体栈：`-apple-system, PingFang SC, Hiragino Sans GB, Microsoft YaHei, Source Han Sans SC`；标题花体 `Snell Roundhand / Brush Script MT` |
| 间距 | 区块 `30 px`；卡片内 `13–17 px`；网格 `12–16 px`；main 内边距 `30 px` |

## 6. 组件规范

### 6.1 Header
- 高 `64 px`；浅色黑底 `#161616`、深色近黑 `#0c0c0b`；底部 3 px 亮黄边。
- 左侧花体 `Onboarding` + 竖分隔线 + 「每日成长工作台 / 我的 90 天」；花体与右侧两行垂直中线对齐（`align-items:center` + `translateY(1px)`）。
- 右上角：太阳/月亮 switch（浅色显示月亮、深色显示太阳）→ 铃铛（亮黄通知点）→ 黄色圆形头像（`#ffd21f`）。

### 6.2 导航（响应式）
- 宽屏（≥ 900 px）：左侧竖导航，宽 `minmax(196px, 15%)`，右 main。
- 窄屏（< 900 px）：导航变顶部横向 capsule tab（`flex-direction:row; overflow-x:auto`）。
- 选中态：浅色黑底白字，深色黄底黑字（`--btn-bg`）。

### 6.3 统计卡（今日 / 待办 / 已完成）
- 三列网格；左图标（42 px 圆角方块）+ 右文字（标签 / 大数字 / 提示）。
- 浅色：今日卡柠檬黄底、图标白底蓝字；深色：今日卡黄调半透明底、图标自动切霓虹。

### 6.4 旅程卡（90 天地图）
- 浅色：柠檬黄底 + 2.5 px 黑边 + 6 px 蓝硬影。深色：深琥珀底 + 亮黄描边 + 黑硬影。
- 内含：起止日期条、总进度条、5 站（破冰→工具→提问→规划→压力）、当前站亮黄圆 + 蓝色光圈（浅色）/ 黑圈（深色）、里程碑文案 + 「查看清单」按钮（深色下黄底黑字）。

### 6.5 成长线（四条）
- 两列网格；左彩色图标 + 右名称 / 进度条 / 计数（`11 项 · 已做 4`）。
- 选中态：浅色蓝描边，深色黄描边（`--blue` 映射）。
- 底部详情条：图标 + 名称·百分比 + 描述 + 主按钮（`--btn-bg` 黑/黄）。

### 6.6 任务行 + 勾选按钮（check）
- 左 check + 中标题/标签/来源 + 右箭头；hover 上浮 + 描边变 `--blue`。
- **check 按钮（多巴胺式）**：29 px 圆角方形（`border-radius:9px`），2.5 px 描边；
  - 未完成：卡片底 + 主题描边，内部勾不可见；
  - 完成：`--btn-bg` 底 + `--btn-fg` 勾（浅色黑底白勾、深色黄底黑勾）；
  - hover `scale(1.07)`。
- 任务 tab：今日 / 待办 / 已完成，选中态深色黄底黑字。
- 个人待办带 `我的待办` 黄色标签；空态虚线框 + 提示文案。

### 6.7 双入口（底部）
- 两列；左 46 px 图标块 + 中标题/描述 + 右「去提问 / 查看指南」箭头；hover 上浮。

### 6.8 伙伴与提问
- 伙伴卡：左头像（40 px 圆）+ 右姓名/角色 + 角色标签；导师卡柠檬黄底，其余白/卡底。
- 提问路径表：问题类型（110 px）/ 渠道说明 / 响应时间胶囊。
- BGTA 四段卡：B/G/T/A 四格 + 主按钮。

### 6.9 工具箱
- 软件指南：可展开手风琴（图标 + 标题 + 状态徽标「学习中/已掌握」），步骤带编号圆点，可标记已掌握（localStorage 记忆）。
- 每日小站：8 个小工具卡（左图标右文字）：答题闯关 / 破冰话题 / BGTA 提问生成 / 方块呼吸 / 54321 着陆 / 4-7-8 助眠 / 猜词游戏 / 提神站。
- 常用网址：10 个链接卡（左彩色图标 + 名称 + 域名·用途），新窗口打开。

### 6.10 Modal / Toast
- Modal：2.5 px 描边 + 16 px 圆角 + 8 px 硬影，内 padding 24 px；kicker 用 `--blue`（深色变黄）。
- Toast：`--btn-bg` 底（浅黑/深黄）+ `--btn-fg` 字，底部居中胶囊。

## 7. 排版规范

1. **字体**：正文使用知乎体栈；标题 `Onboarding` 用花体。
2. **中英/中数之间必须空格**（「入职第 3 天」「BGTA 四段式」「P0 软件清单」）。
3. **标点**：以中文为主时用全角标点（，。；：（）「」）；纯英文场景才用半角。
4. **禁 emoji**：图标一律 Material Icons 内联 SVG；字符画除外。

---

## 8. 图标规范

- 全部使用 Google Material Icons 官方 path，内联 `<svg class="mi">`，零网络依赖。
- 尺寸：通用 20 px；卡片图标块 19–23 px；小图标 15–17 px。
- 颜色：`fill:currentColor`，由所在容器 color 控制；彩色图标块用多巴胺 fg/bg。
