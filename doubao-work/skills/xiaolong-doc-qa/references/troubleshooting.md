# 常见问题排查

## 链接打不开 / 抓不到正文

| 现象 | 原因 | 处理 |
|---|---|---|
| 抓到的是登录页 / 只有标题没有正文 | 文档没开公开权限 | 让文档所有者：右上角「分享」→ 权限改为「互联网上获得链接的人可阅读」→ 重新给链接 |
| 链接 404 / 页面不存在 | 链接失效或已删除 | 请用户确认链接，或换一份文档 |
| 页面是纯 JS 渲染、正文为空 | 个别页面需登录后才出正文 | 改用「用户粘贴正文」方式建库 |
| 内容只有一半 | 页面懒加载 | 滚动加载后再抓，或分段抓取后合并 |

## 文档很长 / 内容很多

- 超过 10000 字先按一级标题切块，逐块读取再合并索引，不要一次性全文读入。
- 回答时只定位最相关的 1-3 块，不要每次重读全库。

## 表格怎么处理

- 表格必须转成文本清单（「技能名：用途，链接」），否则问答时信息会丢。
- 数字类表格（人数、金额、行数）逐行保留，不要四舍五入或省略。

## 问答不准 / 答非所问

- 先检查索引是否漏块：索引建好后问用户「有 N 块，对吗」，漏了就补。
- 回答必须引原文：宁可少说，不要用模型记忆替换文档内容。
- 文档真没有的内容，明说「文档里没提到」，不编造。

## 出题相关问题

- 题量默认 ≤20 道；题型单选/多选/判断均可。
- 每道题必须标注出处块编号，方便用户回查。
- 只从文档内容出题，不掺文档外知识。

## 隐私提醒

- 公开链接 = 任何拿到链接的人都能读，含敏感信息的文档不要公开。
- 用户需要保密时，改用「粘贴正文」方式建库，不要贴公开链接。
