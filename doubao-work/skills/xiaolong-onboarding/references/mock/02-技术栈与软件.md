# 技术栈与软件（Mock）· 该装什么、用什么技术栈

> 虚构演示数据（示例科技）。真实使用时由用户自己的 onboarding 文档替换。

## 一、入职软件清单（按优先级）

### P0 · 第一天必须装（没有就没法干活）

| 类别 | 软件 | 用途 | 账号 / 安装 |
|---|---|---|---|
| 通讯协作 | 飞书 | 聊天、会议、文档、日程 | 企业邮箱登录，入职邮件有邀请链接 |
| 文档 | 飞书文档 / 知识库 | 阅读和撰写文档 | 同上 |
| 代码 | Git + 公司代码平台客户端 | 拉代码、提交 | 企业邮箱开通，见 code.example.com |
| 浏览器 | Chrome（公司版） | 内部系统兼容 | 默认安装 |
| 安全 | VPN 客户端 | 远程访问内部系统 | IT 工单开通后下发配置 |

### P1 · 第一周装好

| 类别 | 软件 | 用途 |
|---|---|---|
| IDE | VS Code + 团队统一插件集 | 写代码（插件清单见团队 wiki） |
| 终端 | iTerm2 / 系统终端 | 命令行 |
| 包管理 | Homebrew、Node.js ≥ 20、pnpm | 前端环境 |
| 设计稿 | Figma 桌面版 | 看设计稿和标注 |
| 协同 | 飞书妙记（会议纪要）、任务中心 | 会议与待办 |

### P2 · 按需安装

| 类别 | 软件 | 用途 |
|---|---|---|
| 数据库工具 | TablePlus / DataGrip | 连数据库 |
| 接口调试 | Postman / Apifox | 调接口 |
| 容器 | Docker Desktop | 本地起服务 |
| 监控 | 公司监控平台客户端（可选） | 看线上指标 |

> 安装遇到权限问题一律走 IT 工单，不要用个人账号注册公司软件。

## 二、技术栈概览（按岗位）

| 方向 | 主要技术栈 | 说明 |
|---|---|---|
| 前端 | React 18 + TypeScript + Vite，组件库见《组件与网址》 | 中后台以 React 为主，H5 用同栈 |
| 后端 | Go + 微服务（gRPC），Python 用于脚本/数据服务 | 服务在内部平台发布，灰度发布流程见 wiki |
| 客户端 | iOS（Swift）/ Android（Kotlin）双端，跨端小功能用 Flutter | 按团队分工 |
| 数据 | SQL + ClickHouse 看板，Python 做分析 | 数据平台见《组件与网址》 |
| AI | 豆包大模型 API + 内部 Agent 平台 | 新项目先查平台是否有现成能力 |

## 三、第一个月要能回答的问题

1. 我的项目用哪套技术栈？构建和测试命令是什么？
2. 代码怎么提交、怎么走 Code Review？
3. 本地怎么起服务、怎么连测试环境？
4. 上线走什么流程、灰度怎么开、怎么回滚？
5. 线上指标在哪看、告警找谁？

> 以上答案都在团队 wiki 和代码库 README 里，找不到就问 leader。
